# Skin Doctor Website

Open `index.html` in a browser. The homepage links to the complete set of supporting pages under `pages/`:

- About, contact, services, and knowledge centre
- Individual service pages for skin, hair, nail, cosmetic, pigmentation, eczema, psoriasis, and vitiligo topics
- Individual patient information articles
- Dermatology assistant demo

Shared styles and assistant interactions are in `css/style.css` and `js/site.js`. Images are in `public/images/`.
